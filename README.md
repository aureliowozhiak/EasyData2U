# EasyData2U
# Ferramenta de Extração e Manipulação de Dados

## Sobre o Projeto
Este projeto tem como objetivo democratizar o acesso à extração, manipulação e análise de dados, permitindo que qualquer pessoa, independentemente de conhecimento técnico, possa trabalhar com dados de forma simples e eficiente. A ferramenta conta com uma interface intuitiva e amigável, projetada para facilitar o uso por pessoas sem experiência prévia em tecnologia ou programação.

## Funcionalidades Principais
- **Extração de Dados:** Conecte-se a diversas fontes de dados, como arquivos CSV, planilhas, bancos de dados e APIs, com poucos cliques.
- **Manipulação de Dados:** Realize operações comuns, como filtrar, ordenar, agrupar, e transformar dados, tudo através de uma interface visual.
- **Análise de Dados:** Crie gráficos e relatórios básicos para entender seus dados rapidamente.
- **Exportação Simplificada:** Salve os dados manipulados em formatos como CSV, Excel ou JSON para uso posterior.

- Profissionais de marketing e vendas
- Estudantes e pesquisadores
